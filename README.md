# PulseSync Module Template

Шаблон JavaScript-модуля на TypeScript и Vite. Пишете код, собираете один файл и отправляете его на проверку через кабинет разработчика.

Шаблон самого аддона — в ветке `dev`.

## Начало работы

Нужны Node.js 20+ и Yarn.

```sh
yarn install
yarn build
```

Готовый файл: **`dist/module/module.js`**.

## Где писать код

- `src/module.ts` — логика модуля. В примере — функция `formatLabel`.
- `src/module-api.ts` — тип экспортируемых функций и версия API (`apiMajor`).
- `vite.config.ts` — настройки сборки.

`yarn dev` пересобирает модуль при изменениях, `yarn typecheck` проверяет типы, `yarn format` форматирует код.

Если меняете API несовместимым образом, увеличьте `apiMajor`. Подписки и таймеры очищайте в `dispose`, возвращаемом из `create`.

## Как опубликовать

1. В кабинете разработчика создайте модуль и версию типа **JavaScript**.
2. Укажите API из `src/module-api.ts` — по умолчанию `1`.
3. Загрузите `dist/module/module.js`, сохраните и отправьте на проверку.
4. После одобрения опубликуйте версию в нужный канал.
5. Разместите тот же файл на своём сервере: копия в PulseSync удаляется после модерации.

Публичный и защищённый модули собираются одинаково — доступ к защищённому файлу проверяет ваш сервер лицензий.

## Как подключить

В конфигурации аддона укажите UUID модуля, его API и канал под своим именем, например `label_formatter`. Передайте в `modules.load('label_formatter', { fetch })` функцию, которая скачивает файл с вашего сервера и возвращает `Uint8Array`. Она получает `{ descriptor, signal }`: выбирайте файл по `descriptor.versionId`, передавайте `signal` в `net.fetch` и добавьте адрес сервера в `allowedUrls`. Для защищённых файлов используйте авторизацию своей системы лицензий. Ошибку обработайте через `try/catch`.

PulseSync проверяет одобренный хеш перед запуском. Пример загрузчика — в [README SDK](https://github.com/PulseSync-LLC/PulseSync-addon-sdk#модули-аддона).

Для WASM нужен компилятор выбранного языка. Полученный бинарный `.wasm` загружается в версию типа **WebAssembly**.
